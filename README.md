# Учёт времени по геолокации

Приложение для учёта рабочего времени сотрудников с привязкой к геолокации.

## Стек
- **React + Vite** — фронтенд
- **Supabase** — база данных (PostgreSQL)
- **PWA** — работает офлайн, можно установить на телефон

## Возможности
- 🔐 Логин/пароль для админа и сотрудников
- 👑 **Админ:** добавляет/деактивирует сотрудников, видит все смены
- 👷 **Сотрудник:** начинает/завершает смену, видит свои часы
- 📍 Геолокация при старте и завершении смены
- 📊 Отчёты по сотрудникам
- 📱 Адаптив (телефон + ПК)
- 🏠 PWA — устанавливается как приложение

## Запуск локально
```bash
npm install
npm run dev
```

## Деплой
1. Залей на GitHub
2. Подключи к [Vercel](https://vercel.com)
3. Build: `npm run build`, Output: `dist`

## Supabase
1. Создай проект на https://supabase.com
2. Выполни SQL из папки `supabase/schema.sql`
3. Скопируй URL и anon key в `src/lib/supabase.js`

## Первый вход
- Логин: `admin`
- Пароль: `admin123`

## Мультитенантность
Каждый сотрудник видит только свои смены. Админ видит все.
