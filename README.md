# Учёт времени по геолокации

PWA для учёта рабочего времени сотрудников с привязкой к геолокации.

## Возможности

- 🔐 Авторизация по логину/паролю
- 👑 Админ: добавление/удаление сотрудников
- 👷 Сотрудник: начало/конец смены
- 📍 Геолокация при старте и завершении
- 📊 Отчёты по всем сотрудникам
- 📱 PWA: установка на телефон, адаптивный дизайн
- 🔄 Realtime синхронизация через Supabase

## Стек

- React 18 + Vite
- Supabase (PostgreSQL + Auth + RLS)
- Service Worker (PWA)

## Деплой

1. Создай проект на [supabase.com](https://supabase.com)
2. Выполни SQL из файла `supabase-init.sql`
3. В `src/lib/supabase.js` укажи свой URL и anon key
4. Подключи репо к [vercel.com](https://vercel.com) — автодеплой

## Демо

- Админ: `admin` / `admin123`
